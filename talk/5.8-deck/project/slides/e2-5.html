Equality is a type class

trait Eq[A] {

def eqv(x: A, y: A): Boolean

}

object Eq {

implicit def universal[A]: Eq[A] = new Eq[A] {

def eqv(x: A, y: A): Boolean = x == y

}

val caseInsensitive: Eq[Char] = new Eq[Char] {

def eqv(x: Char, y: Char): Boolean = Character.toLowerCase(x) == Character.toLowerCase(y)

}

}

Stage 3, already in 2.5. Universal == is hardwired, so equality becomes a type class: the default instance lives in Eq's companion and is found through the implicit scope. Eq.caseInsensitive is an opt-in val you pass explicitly or put in scope as an implicit. No lambdas can implement a trait yet, hence the anonymous classes.
