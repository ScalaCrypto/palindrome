New in Scala 2.5

Type constructor polymorphism

type parameters that take type parameters, like F[_]

Early object initialization

fields set before the parent constructor runs

Placeholder syntax for lambdas

_ + 1 for x => x + 1

Revised for-comprehensions

a new syntax for generators and filters

Case clauses as functions

{ case (a, b) => … } for more than one argument

Where the tour starts, May 2007. These are 2.5's own changes, from the language specification's changelog. None of them is in amber: the 2.5 code uses none of them. Its one lambda is written out (i => ...), and everything it needs, generics, implicit parameters and conversions, anonymous classes, Scala already had. That's the point of starting here: the design is expressible before the conveniences arrive.
