The whole design with 2007 machinery. No +: and :+ extractors yet, so it's index arithmetic; the call is in tail position, even inside || and &&, so scalac already compiles it to a jump, but nothing checks that. palindromize finds the longest palindromic suffix with our own isPalindrome, so it takes an Eq too, and mirrors what comes before it. Generic code can't build the same kind of collection, so it returns a Seq: "abcb" gives a Seq[Char], not a String.
