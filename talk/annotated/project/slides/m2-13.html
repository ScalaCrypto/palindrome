The 2.12 code stops compiling for String: StringOps is no longer a collection, so Repr is inferred as WrappedString. IsSeq accepts anything readable as a Seq, String included; BuildFrom replaces CanBuildFrom. The wart: Scala 2 can't mention seq.A in the same parameter list as seq, so the element type becomes an extra type parameter A0, tied by a refinement.
