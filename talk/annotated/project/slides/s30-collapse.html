Talk stages 4 and 6 in one table: the diff between 2.13 and 3.0 is the headline of the 2 to 3 transition, and it reads in seconds. given for implicit def, using for implicit, braces gone, extension for the implicit class, and object Palindrome disappears because Scala 3 has top-level definitions.
