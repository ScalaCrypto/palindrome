The goal

Equality for Any

trait Eq[A] {

  def eqv(x: A, y: A): Boolean

}

Any element type needs an equality, and the caller should decide what "the same element" means: plain == for most types, case-insensitive for Chars if they ask. So equality becomes a type class, Eq[A], with one method. Both functions take an Eq for their element type. This is the trait as Scala 2.5 writes it; the default instance and the case-insensitive one come with 2.5's code.
