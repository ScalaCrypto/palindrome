Scala 2.10 · 2013 → 2.11 · 2014

Wrapper and conversion become one implicit class

// 2.8: a class, plus a conversion to it

class PalindromeOps[A, Repr](xs: SeqLike[A, Repr]) { … }

implicit def palindromeOps[A, Repr](xs: SeqLike[A, Repr]): PalindromeOps[A, Repr] =

  new PalindromeOps(xs)

 

// 2.10: one declaration, and a value class, so usually no allocation

implicit class PalindromeOps[A, Repr](val xs: SeqLike[A, Repr]) extends AnyVal { … }

 

// 2.11: the wrapped field may be private

implicit class PalindromeOps[A, Repr](private val xs: SeqLike[A, Repr]) extends AnyVal { … }

Talk stage 6, first step. The wrapper carries Repr so that xs.palindromize can return the caller's type. 2.10 insists the value class's field is public; 2.10 rejects private val with "value class needs to have a publicly accessible val parameter". 2.11 relaxes that, so the wrapped Seq no longer leaks as a public member of every Seq. Strings still can't use method syntax in Scala 2 up to 2.12: implicit views don't chain (String to WrappedString to PalindromeOps).
