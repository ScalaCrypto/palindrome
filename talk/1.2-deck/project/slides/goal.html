The goal

Any Seq[A], called as a method

Both functions should take a Seq of any element type, and read as extension methods on Seqs and Strings.

"racecar".isPalindrome         // true

List(1, 2, 1).isPalindrome     // true

Vector('a', 'b').isPalindrome  // false

"abc".palindromize             // a String

List(1, 2, 3).palindromize     // a List[Int]

Where we want to get to: the same two functions, for any Seq and any element type, called as methods. A String is not a Seq, so it has to be converted on the way; until 2.13 that conversion won't chain with our own wrapper, so "racecar".isPalindrome only works from 2.13 on, and earlier versions write isPalindrome("racecar"). palindromize should also hand back the collection it was given: a String for a String, a List for a List.
