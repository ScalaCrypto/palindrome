Scala 3.6 · 2024

Givens and context bounds get names

A given now reads “for every A, an Eq[A]”, and a named context bound folds the using clause into the type parameter. 3.5 rejects both.

− given universal[A]: Eq[A] = _ == _

+ given universal: [A] => Eq[A] = _ == _

 

− extension [A](xs: Seq[A])(using eq: Eq[A])

+ extension [A: Eq as eq](xs: Seq[A])

 

− extension [Repr](xs: Repr)(using seq: IsSeq[Repr])

+ extension [Repr: IsSeq as seq](xs: Repr)

The whole 3.5 to 3.6 diff. eq and seq stay usable by name in the body, and seq.A still works in palindromize's BuildFrom.
