Stage 0

It starts as a one-liner

def isPalindrome(s: String): Boolean = s == s.reverse

Implicits from line one

s.reverse only works because String is enriched to StringOps.

Elegant, and wasteful

It allocates a full reversed copy just to compare.

False before 2.8

In 2.7, "racecar".reverse == "racecar" is false: no content equality.

Old ways: this is beautiful. New ways: it is also the wasteful version, and on 2.7 it's simply wrong, because collection == wasn't content-based before the 2.8 redesign. That's why no version in the repo uses it: every version compares elements pairwise through Eq instead. Generalizing to Seq[A] is free from here (stage 1).
