Scala 2.12 · 2016

Type class instances become lambdas

Eq has a single abstract method, so a lambda can implement it. 2.11 answers: “missing parameter type”.

− implicit def universal[A]: Eq[A] = new Eq[A] {

−   def eqv(x: A, y: A): Boolean = x == y

− }

+ implicit def universal[A]: Eq[A] = (x, y) => x == y

 

− val caseInsensitive: Eq[Char] = new Eq[Char] {

−   def eqv(x: Char, y: Char): Boolean = x.toLower == y.toLower

− }

+ val caseInsensitive: Eq[Char] = (x, y) => x.toLower == y.toLower

SAM conversion: two anonymous classes shrink to one line each. A good moment for the old-ways speaker to concede one.
