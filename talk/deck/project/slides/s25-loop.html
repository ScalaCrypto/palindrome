Index loop, and a conversion for methods

def checkPalindrome[A](xs: Seq[A])(implicit eq: Eq[A]): PalindromeResult = {

  def loop(from: Int): PalindromeResult = {

    val to = xs.length - 1 - from

    if (from >= to) PalindromeResult.Palindrome

    else if (eq.eqv(xs(from), xs(to))) loop(from + 1)

    else PalindromeResult.BreaksAt(from)

  }

  loop(0)

}

class PalindromeOps[A](xs: Seq[A]) {

  def isPalindrome(implicit eq: Eq[A]): Boolean = Palindrome.isPalindrome(xs)

}

implicit def palindromeOps[A](xs: Seq[A]): PalindromeOps[A] = new PalindromeOps(xs)

No +: and :+ extractors yet, so it's index arithmetic. The loop is tail-recursive, and scalac already compiles it to a jump (javap shows a backward goto), but nothing checks that. Method syntax: an implicit def converts any Seq to a wrapper. Oddities worth one sentence: PalindromeResult.Palindrome is qualified because importing it would clash with object Palindrome, and the wrapper must call Palindrome.isPalindrome or it would call itself.
