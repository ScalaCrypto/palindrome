An extension is also a function

enum PalindromeResult:

  case Palindrome

  case BreaksAt(index: Int)

extension [A](xs: Seq[A])(using eq: Eq[A])

  def checkPalindrome: PalindromeResult =

    @tailrec

    def loop(ys: Seq[A], from: Int): PalindromeResult = ys match

      case x +: middle :+ y =>

        if eq.eqv(x, y) then loop(middle, from + 1) else BreaksAt(from)

      case _ => Palindrome

    loop(xs, 0)

  def isPalindrome: Boolean = xs.checkPalindrome == Palindrome

"racecar".isPalindrome and isPalindrome("racecar") are the same method.

An extension method compiles to an ordinary method with the receiver as its first parameter, so there's no wrapper class and no separate top-level def. Bonus contrast: "racecar".isPalindrome works because an extension's receiver may be converted (String to Seq[Char]); Scala 2 needed 2.13's IsSeq wrapper for that, because its implicit views don't chain. Eq.caseInsensitive is passed with (using …), and a local given overrides the companion default.
