An extension is also a function

extension [A](xs: Seq[A])(using eq: Eq[A])

  @tailrec

  def isPalindrome: Boolean = xs match

    case x +: middle :+ y => eq.eqv(x, y) && middle.isPalindrome

    case _ => true

"racecar".isPalindrome and isPalindrome("racecar") are the same method.

The recursion reads middle.isPalindrome, and @tailrec still checks it: it is the same method. An extension method compiles to an ordinary method with the receiver as its first parameter, so there's no wrapper class and no separate top-level def. Bonus contrast: "racecar".isPalindrome works because an extension's receiver may be converted (String to Seq[Char]); Scala 2 needed 2.13's IsSeq wrapper for that, because its implicit views don't chain. Eq.caseInsensitive is passed with (using …), and a local given overrides the companion default.
