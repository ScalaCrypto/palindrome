Match a field by its name

Named tuples went stable, and with them named patterns. Only the tests use it: the implementation has no pattern that benefits.

val index = "abcxba".checkPalindrome match

  case BreaksAt(index = i) => i

  case Palindrome          => -1

assert(index == 2)

3.6 rejects BreaksAt(index = i). A quick slide: say it, move on. 3.8 and 3.9 change nothing this example uses.
