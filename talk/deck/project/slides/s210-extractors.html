Talk stage 2. It parses as (x +: middle) :+ y, because an operator's first character sets its precedence and + binds tighter than colon: :+ splits off the last element, +: the first. Caveat to say out loud: on a List, :+ needs init and last, which are O(n), so this lovely version is quietly O(n²). An IndexedSeq such as Vector keeps it linear. Elegant by default, but know when the data structure betrays you.
