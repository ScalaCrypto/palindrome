Where isPalindrome ends up

"racecar".isPalindrome                            // true

Seq("a", "b", "a").isPalindrome                   // true

"hello".isPalindrome                              // false

"Racecar".isPalindrome(using Eq.caseInsensitive)  // true

"abcb".palindromize                               // "abcba", a String

List(1, 2, 3).palindromize                        // List(1, 2, 3, 2, 1)

From a String-only one-liner to a generic, fluent API driven by a type class, and every feature earned its place.

End on Seq("a", "b", "a").isPalindrome, the closer from the talk spec. Five of the six lines appear as-is in the 3.9 test suite; the Seq line is tested there as List("a", "b", "a"). If asked: the whole source is in v3_9/src/Palindrome.scala, about 35 lines with comments.
