A library change, not a language one: 2.9 adds tails, every suffix from the whole sequence down to the empty one. indexWhere returns the first that's a palindrome, which is where the mirrored part starts. Same search, same order and cost as 2.8's (0 to n).find(...).get, without the index arithmetic or the .get. 2.10 to 3.9 keep it.
